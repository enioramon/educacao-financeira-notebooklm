# 📘 Educação Financeira com NotebookLM

Este repositório faz parte de um desafio do curso **GenIA e Dados** da DIO.

## 🔎 Sobre o projeto
O projeto consiste na criação de um caderno temático no NotebookLM com foco em **Educação Financeira**, utilizando fontes abertas (PDF e textos) para apoiar o estudo introdutório do tema.

No NotebookLM foram definidos:
- Objetivos de aprendizagem
- Perguntas estratégicas
- Testes de variações de prompts
- Resumos estruturados
- Glossário de conceitos
- Prompts reutilizáveis para revisões futuras
